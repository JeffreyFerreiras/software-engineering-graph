Use $code-review to review all uncommitted changes against HEAD in this repository.

This is a review-only task. Do not edit files. Inspect the diff, surrounding contracts, callers, and executable contract checks. Run read-only validation when it helps establish a finding.

Return only the requested structured response. For a SOLID finding, set `category` to `SOLID principle`, use the principle's full name, and leave `pattern` empty. For a pattern opportunity, set `category` to `pattern opportunity`, leave `principle` empty, and name the pattern. Omit optional style preferences and findings without a concrete failure mode or maintenance cost.
